# Al Quran Web App — Website Design Implementation Plan

## Project Overview
A Next.js 14 + Tailwind CSS + React 18 + TypeScript Quran web application with a well-structured component architecture, light/dark themes, and multi-language support (EN/BN/AR). Currently MVP-grade with partial data (~22 of 114 surahs, 20 hardcoded verses).

## Skills Leveraged
| Skill | Relevance |
|---|---|
| **imagegen** | Generate visual assets (Islamic geometric patterns, hero banners, achievement icons, loading animations, favicon, social media cards) |
| **developing-with-streamlit** | Not applicable (this is a Next.js app, not Streamlit) |
| **Built-in patterns** | Tailwind CSS animations, CSS variables design system, React context providers — already established in codebase |

---

## Implementation Phases

### Phase 1: Visual Polish & Animations
**Goal:** Elevate the existing design system with modern visual effects

1. **Enhanced Design Tokens** (`globals.css`)
   - Add glass-morphism utilities (`backdrop-blur-xl`, frosted-glass class)
   - Add refined gradient utilities for section-specific headers
   - Add shimmer/pulse skeleton loading animations
   - Add `IslamicPattern` overlay utilities using SVG background patterns
   - Implement smooth theme transition (CSS `transition: all 0.4s ease`)

2. **New UI Components** (`components/ui/`)
   - `Skeleton.tsx` — Shimmer-loading skeleton for verse cards, surah lists
   - `GradientDivider.tsx` — Section dividers with Islamic geometric SVG + gradient
   - `FloatingActionButton.tsx` — FAB for quick actions (bookmark, share, audio)
   - `Tooltip.tsx` — Accessible hover tooltips for icons
   - `Modal.tsx` — Generic modal/dialog for settings, confirmations
   - `Toast.tsx` — Notification toasts for actions (bookmarked, settings saved)

3. **Animation Enhancements**
   - Page transitions: `AnimatePresence`-style fade between routes (client-side)
   - Staggered card entrance animations for surah library grid
   - Verse reveal animations in the reader (slide-up per verse)
   - Micro-interactions: button press ripples, card hover parallax lift
   - Smooth scroll behavior for surah navigation

4. **Visual Asset Generation** (via `imagegen` skill)
   - Hero banner for homepage (Islamic geometric art, subtle)
   - Achievement badge icons for Hifz dashboard (lock/unlock states)
   - Favicon and meta icons
   - Loading screen splash asset

---

### Phase 2: Content & Data Completeness
**Goal:** Complete the Quran content with all 114 surahs

1. **Centralized Data Module** (`lib/data/quran.ts`)
   - Complete `SURAH_DATA` array with all 114 surahs (name, Arabic name, English name, Bangla name, ayah count, revelation type, Juz count)
   - Export typed helpers: `getSurahs()`, `getSurah(n)`, `searchSurahs(q)`, `getSurahsByJuz(n)`, `getJuzBoundaries()`
   - Remove all inline data duplications across pages/components

2. **Quran Data Integration**
   - Fetch full Quran text from a reliable API (e.g., `alquran.cloud` or similar) at build time
   - Cache static data in `lib/data/` for offline-first reading
   - Add transliteration + all 3 translations (English, Bangla, Arabic) per verse

3. **API Enhancement** (`app/api/search/route.ts`)
   - Full-text search across all 114 surahs (Arabic, English, Bangla)
   - Fuzzy matching for Arabic and Bengali scripts
   - Pagination (10 results/page)
   - Search suggestions/autocomplete

4. **Surah Reader Enhancement**
   - Display all verses for all 114 surahs (not just 8 sample surahs)
   - Ayah numbering in both Eastern and Western Arabic numerals
   - Tafsir (commentary) toggle per verse

---

### Phase 3: New Features
**Goal:** Add meaningful interactive features

1. **Bookmarks & Notes** (`components/ui/`)
   - `BookmarkManager.tsx` — Manage bookmarked verses with surah/verse reference
   - `NoteEditor.tsx` — Add personal notes to any verse
   - `HighlightPalette.tsx` — Color-coded verse highlighting (yellow, green, blue, pink)

2. **Audio Playback** (`components/quran/`)
   - `AudioPlayer.tsx` — Fixed bottom audio bar with play/pause, skip, repeat
   - `AyahAudio.tsx` — Per-ayah audio with highlighted text sync
   - Support multiple reciters (Shuraim, Al-Sudais, Alafasy via `alquran.cloud` API)

3. **Settings Enhancements**
   - Reader font presets (Amiri, Noto Naskh Arabic, Uthmani)
   - Verse display layout options (Arabic-only, Arabic+Translation, Full)
   - Export/Import all data as JSON backup
   - Reading timer and daily goal setter

4. **Social & Sharing**
   - `ShareVerse.tsx` — Generate a styled verse image for sharing (via `imagegen` or canvas)
   - Copy verse text with attribution
   - Share to social platforms

5. **Hifz Dashboard Enhancements**
   - Spaced repetition revision scheduler
   - Memorization progress tracker (per-surah verse-level)
   - Weak verse identification and targeted review

---

### Phase 4: Performance Optimization
**Goal:** Ensure fast, smooth, accessible experience

1. **Next.js Optimization**
   - Enable `output: 'export'` or ISR for static surah pages
   - Implement `next/font` self-hosting (currently using Google Fonts CDN)
   - Add `next/image` with proper srcset and lazy loading
   - Code splitting: lazy-load heavy components (CalendarHeatmap, ReadingStatistics, Confetti)
   - Bundle analysis to identify and eliminate unused code

2. **Data Fetching**
   - Implement React Server Components where possible (surah data, library)
   - Add SWR or React Query for search API with caching
   - Stale-while-revalidate for surah pages

3. **Build & Runtime**
   - Add ESLint + Prettier config
   - Tree-shake unused Tailwind classes with PurgeCSS
   - Enable gzip/brotli compression
   - Add Sentry or similar error tracking

4. **Accessibility**
   - ARIA labels on all interactive elements
   - Keyboard navigation for surah reader and search
   - Screen reader support for Arabic text
   - Focus management for modals and modals
   - Color contrast audit (WCAG AA)

5. **PWA Support**
   - `manifest.json` for installability
   - Service worker for offline reading (cached surah data)
   - App icon set for all device sizes
