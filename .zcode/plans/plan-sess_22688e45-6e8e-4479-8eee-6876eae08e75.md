## Premium Classic UI Redesign — Al Quran Web

A cohesive rewrite of the design system, navigation, and top-level chrome that delivers the requested **timeless cream + soft gray + gold** aesthetic with classic typography, a unified left nav (Home, Surah, Hifz, Library, Duas, Stats, Settings), and a top-right profile/stats element — all on the existing Next.js 14 App Router, staying lean for instant localhost perf.

**Decisions made via best judgment (no user answers received):**
- **Color**: Full rebrand to cream/gold as the sole theme. Replace emerald primary + majestic-blue chrome with warm cream surfaces, soft gray borders, and gold as the global accent. (Bengali + Arabic text unchanged.)
- **Typography**: Inter (UI/body) + Lora (display/headings), keep Amiri (Arabic) + Hind Siliguri (Bengali). All via `next/font/google`.
- **Duas**: Build a real `app/duas/page.tsx` with curated daily duas rendered in the new card system.
- **Profile**: Avatar top-right that opens a dropdown popover with mini reading stats (from existing localStorage) + Settings; "Sign in" CTA when no stats (non-functional stub).

### Phase 1 — Design token system & fonts (foundation)

- Light: `--bg #FAF7F0` (cream), `--surface #FFFDF8`, `--surface-highlight #F3-EDE0`, `--text #2C2A26` (warm ink), `--text-muted #6B655A`, `--border #E8E2D5`, `--gold #B8964A`, `--gold-dark #9A7A3C`, `--gold-soft #D0A85E`.
- Dark (warm): `--bg #1A1814`, `--surface #23211B`, `--surface-highlight #2C2922`, `--text #F2EDE0`, `--text-muted #B0A896`, `--border #3A352C`, gold stays a touch lighter `--gold #C9A961`.
- Add the missing tokens that broken components reference, mapped onto the new palette: `--surface-1/2/3` (surface ramp), `--ink/ink-2/ink-3/ink-4` (= text + text-muted ramp), `--border-default`, `--border-subtle`, `--surface-elevated`, `--surface-muted`, `--bg-subtle`, `--shadow-elevated`, `--majestic-darker`, `--gold-light`.
- Keep `--primary` but alias it to gold (`--gold`) so semantic `primary` classes (used widely in components) now render gold instead of emerald. Keep `--quran/--hifz/...` per-section colors at muted, lower-saturation values (reused as subtle section tints, no rainbow gradients).
- Rebuild `--font-ui` to use the Inter next/font var.
- Keep all existing keyframes/animations/`.islamic-pattern`/`.glass`/`.shimmer`/`.card-lift`/`.btn-ripple` utilities; refine `.gradient-header-gold` and add `.ornamental-divider` classic flourish. Add prefers-reduced-motion guards (already present).

**`app/layout.tsx`** — add Inter + Lora via `next/font/google` (with Arabic + Bengali weight/subset config), expose `--font-ui` (Inter) and `--font-display` (Lora) vars, apply both vars to `<body>`. Update metadata title/description. Wrap shell with the new `TopBar` + left `DesktopSidebar` + `MobileNav`.

**`tailwind.config.js`** — map the new tokens: add `surface-1/2/3`, `ink/ink-2/ink-3`, `border-default`, `border-soft`, `gold-soft`, `surface-elevated`, `surface-muted`. Drop unused `majestic-light/dark` mapping (now aliased to neutral). No new plugins (avoid dependency/build churn).

**`lib/cn.ts`** — unchanged (clsx-only). Keeping it avoids installing `tailwind-merge`; the redesign avoids conflicting-class overrides so clsx suffices.

### Phase 8 — Performance & polish

- **No new runtime deps.** Reuse existing `clsx`. Do NOT add `tailwindcss-animate`/`typography`/`tailwind-merge` (keep build minimal + instant).
- Keep `next.config.js` `images.unoptimized` (current state fine for static assets).
- Ensure all new components are either server components or, where 'use client' is needed (pathname, localStorage, popover), minimal and gated by `mounted` to preserve SSG and avoid hydration mismatches.
- Smooth transitions: keep the existing 0.2–0.4s transitions on cards/buttons; add a 150ms gold focus-ring on all interactive elements for keyboard accessibility. Add `prefers-reduced-motion` guards (already partial).
- **Accessibility**: ensure color contrast WCAG AA on cream/gold combinations (gold text on cream may need `--gold-dark #9A7A3C` for text; tested for ~4.6:1 on cream). All icons paired with `aria-label`/`sr-only` text where decorative. Keyboard-focusable nav, profile popover (focus trap + ESC).

### Scope & non-goals (explicitly OUT of this pass)

- **No auth backend** — profile "Sign in" is a visual stub; stats come from existing localStorage.
- **No new verse corpus** — the reader's limited verse data (surahs 1/112/113/114) stays as-is; "coming soon" placeholders reskinned only.
- **No build/dep upgrades**, no Next.js 14→15, no Tailwind v4, no ESLint/Prettier setup, no tests. Focused purely on the UI redesign.
- Not replacing `QuranReaderClient.tsx`/`FocusMode.tsx`/`AutoScroll.tsx` (unused) — leave them; not rendered.
- Not migrating the duplicated 114-surah data onto `lib/data/quran.ts` (refactor, not UI) — though I'll stop re-declaring partial surah arrays in newly-touched files where cheap.
