## PHASE 4: Improved Audio Player with Per-Ayah Repeat

### 4A. Enhance QuranAudioPlayer
- Add repeat/loop state:
  - `repeatMode: 'none' | 'verse' | 'range'` — persisted in `alquran_audio_settings`
  - `repeatCount: number` — how many times to repeat (1-10)
  - `repeatCounter: number` — current count (internal)
- Modify `onEnded` handler:
  - If `repeatMode === 'verse'` and `repeatCounter < repeatCount`: replay same verse
  - If `repeatMode === 'verse'` and counter reached: auto-advance
  - If `repeatMode === 'range'` and at end: loop back to range start
- Add **loop toggle button** and **repeat count selector** in player settings

### 4B. Add per-verse audio controls (like your screenshot)
- Each verse in SurahReader gets a small inline audio bar (top-right of verse card):
  - `[58:22 ▶ 🔖]` — verse number + play button + bookmark
  - Clicking play starts audio from that specific verse
- Clicking the verse number badge still works as before (triggers player)

### 4C. Per-Ayah Memorization Tracking
- New localStorage key: `alquran_hifz_ayah_progress`
- Structure: `{ [surahNumber]: { [ayahNumber]: { mastered: boolean, practiceCount: number, lastPracticed: timestamp } } }`
- Track which ayahs the user has repeatedly practiced in hifz mode

## PHASE 5: Hifz Practice Page

### 5A. Create new page: `app/quran/hifz/practice/page.tsx`

**Left Panel — Settings:**
- **Surah selector** dropdown (all 114 surahs with English + Bangla names)
- **Start Ayah** number input
- **End Ayah** number input
- **Repeat Each Verse** dropdown: 1, 2, 3, 5, 10, 20, 50 times
- **Delay Between Verses** dropdown: No delay, 3s, 5s, 10s, 15s
- **Repeat Range Loop** dropdown: 1, 2, 3, 5, 10, 20, 50 loops
- **"Start Hifz Loop"** button (gold)
- **Hide Translation** toggle: hide Bangla + English transliteration to test memory

**Right Panel — Player Status:**
- Status banner: "Setup a range and press start" / "Playing: Surah 1:1-7"
- **Active Ayah** display: large number showing current ayah
- **Verse Repeat** counter: e.g., "3/5" (3 of 5 repeats done)
- **Range Loop** counter: e.g., "1/3" (1 of 3 full loops)
- **Pause** / **Stop** buttons
- **Previous** / **Next** controls

**Advanced features:**
- **Mastery progress per ayah**: Visual indicator (empty/stars/full) for each ayah
- **Reciter selection**: Dropdown for audio source
- **Playback speed**: 0.5x to 2x
- **Auto-advance after delay**: After N seconds of silence or user presses "Next"
- **Memory test mode**: Toggle to gradually hide translations, then hide Arabic too

### 5B. Update Hifz Dashboard
- Change "Start Hifz Session" button to link to `/quran/hifz/practice` instead of `/quran/surahs/1`
- Update "Revision Session" to link to practice page
